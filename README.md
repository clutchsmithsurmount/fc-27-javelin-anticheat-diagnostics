## 📁 How It Works — Troubleshooting Workflow

1. Restart Windows and start the game normally from Steam or the EA app.
2. Use Steam Properties > Installed Files > Verify integrity of game files; let Steam complete any repairs.
3. Check the official EA Javelin AntiCheat support page and use EA’s repair/reinstall procedure for service errors.
4. Close controller remappers, debuggers, conflicting overlays and other software explicitly identified in the Javelin error message.
5. Update Windows and signed device drivers, then compare the exact error after a clean restart.
6. Record the error text, timestamp, game version and relevant Event Viewer Application event before reporting an unresolved issue.
